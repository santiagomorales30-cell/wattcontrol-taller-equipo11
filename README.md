# WattControl - Taller de mecanizado

Gestor de energia en C++ con programacion orientada a objetos para un taller de mecanizado (El Nino 2026).
Decide que cargas encender, apagar o aplazar segun la hora, el precio de la energia y el nivel de los embalses, y simula un dia de 24 horas para medir el ahorro.

Compilar: `g++ -Wall -o wattcontrol wattcontrol.cpp`
